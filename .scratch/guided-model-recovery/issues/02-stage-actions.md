# 02: Доступные действия и восстановление после недопустимого выбора

**Что построить:** вопрос предлагает только действия, разрешённые на этапе. Недопустимый ответ даёт модели обратную связь; необходимость ответа человека обрабатывается существующим переходом к проработке. Человек видит выбранный переход в HTML.

**Блокируется:** 01 — использует проверенный механизм ограниченного корректирующего повтора.

**Статус:** ready-for-agent

- [ ] Схема действий соответствует фактическим правам этапа.
- [ ] Запрещённый AskHuman не выполняется и не расширяет права.
- [ ] При необходимости бизнес-уточнения модель не выдумывает ответ; используется разрешённый переход.
- [ ] Интеграционные проверки покрывают ошибку AskHuman из исходной серии, повтор и отмену.
- [ ] HTML показывает допустимые действия, отказ и дальнейший переход.
