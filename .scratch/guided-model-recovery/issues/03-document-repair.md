# 03: Гейт различает рендер документа и потерю проверенных фактов

**Что построить:** ремонт адресованного раздела проходит при изменении оформления с сохранением проверенных фактов. Потеря фактов и изменения нетронутых разделов блокируются. HTML отдельно показывает валидацию JSON и решение гейта.

**Блокируется:** ничем; можно начать сразу, независимо от 01 и 02.

**Статус:** ready-for-agent

- [ ] Сокращение числа строк при JSON→таблица само по себе не означает потерю данных.
- [ ] Сохраняются ID, критерии, основания, цитаты и нетронутые разделы.
- [ ] Удаление данных, подмена ID и изменение документа между проверкой и записью блокируют запись.
- [ ] Нет общего автоодобрения разрушающей перезаписи; сохранены существующие ограничения гейта.
- [ ] Интеграционные проверки проходят через исполнитель и реальный гейт.
- [ ] HTML показывает сравнение фактов и точную причину разрешения/отказа записи.
