# 01: Исправление ошибочного выбора источника в guided-флоу

**Что построить:** модель различает встроенный запрос, существующий файл, каталог и планируемый файл. После неверного чтения получает структурированную обратную связь и ограниченный повтор. Человек видит ошибку и восстановление в HTML.

**Блокируется:** ничем; можно начать сразу.

**Статус:** ready-for-agent

- [ ] Встроенный request-1 разрешается по ID, а не читается с диска.
- [ ] Каталог перечисляется; будущий файл не предлагается для Read; опечатка не исправляется на другой путь молча.
- [ ] Ошибки выбора не обрывают этап на первом промахе; повтор ограничен бюджетом, отменой и защитой от циклов.
- [ ] Интеграционные проверки воспроизводят четыре ошибки чтения из исходной серии.
- [ ] HTML показывает каталог источников, выбор, ошибку, новый вопрос и результат повтора.
