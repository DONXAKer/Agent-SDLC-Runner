# Доменные документы

## Структура

Single-context: для всего Agent-SDLC-Runner используется единый доменный контекст, включая workspaces `shared`, `server`, `web`.

- `GLOSSARY.md` в корне — общий словарь терминов.
- `docs/adr/` — общие архитектурные решения.

## Перед исследованием кода

Читайте корневой `GLOSSARY.md`, если он существует, и ADR из `docs/adr/`, относящиеся к исследуемой области.

Если документы отсутствуют, продолжайте работу без предупреждений и предложений создать их заранее. Скилл `domain-modeling`, вызываемый через `grill-with-docs` и `improve-codebase-architecture`, создаёт их по мере согласования терминов и решений.

## Используйте термины глоссария

В названиях задач, предложениях по рефакторингу, гипотезах и тестах используйте термины из `GLOSSARY.md`. Не заменяйте их синонимами, которых глоссарий явно избегает.

Если необходимого термина нет, проверьте, используется ли он в проекте. Реальный пробел отметьте для `domain-modeling`.

## Противоречия ADR

Если предложение противоречит существующему ADR, явно укажите номер решения и причину, по которой предлагаете его пересмотреть. Не переопределяйте решение молча.
