## Набор

_Строки не удаляются — только переключаются. Обязательный минимум помечен «да — минимум»:
у этих строк переключателя нет, без любой из них набор не собран и виток не стартует._

| Гейт | Вкл | Где отчитывается | Чем реализован |
|---|---|---|---|
| Сборка | да — минимум | этап 6 | `npm run typecheck` — прод исполняет TypeScript напрямую, поэтому «сборка» здесь и есть проверка типов по server и web |
| Тесты | да — минимум | этап 6 | `npm test` — `node:test` по server и web; `*.smoke.ts` в набор намеренно не входят: им нужны Docker и живой Unreal |
| Scope: файлы вне плана | да — минимум | этап 6 | встроенная реализация: `git diff` от базы chunk'а против `files_to_touch`, пути `.sdlc/**` исключены |
| Анти-обход тест-гейта | да — минимум | этап 6 | встроенная реализация: греп по diff'у на отключённые тесты, удалённые тестовые файлы и падение числа прогонов |
| Ревью независимым агентом | да — минимум | этап 6 | субагент `sdlc-reviewer`, модель строго сильнее исполнителя этапа 5; на вход ровно четыре артефакта — задача, план, этот набор, diff |
| Scope: пути плана без правок | да | этап 6 | встроенная реализация: сверка `files_to_touch` ↔ diff в обратную сторону; каждый непокрытый путь получает в отчёте «не потребовалось, потому что X» или «не сделано» |
| Scope: нетракованные файлы | да | этап 6 | встроенная реализация: нетракованные файлы вне `.sdlc/`; игнорируемые git-ом не считаются, не-репозиторий даёт пропуск |
| Секреты в diff | да | этап 6 | встроенная реализация: ключи, токены и файлы окружения в добавленных строках |
| Линт экосистемы | нет | этап 6 | н/п — долг: линтера в проекте нет, `typecheck` и есть проверка (см. `CLAUDE.md`) |
| Дубли хелперов | да | этап 6 | встроенная реализация: эвристика «написал то, что уже есть» |
| Проверка предусловий публикации | да — минимум | этап 7 | встроенная реализация: ветка витка, чистое дерево, отсутствие коммита на `main` |
| Калибровка гейтов посевом | нет | вне витка | н/п — долг: механизм записан (`/sdlc-seed`, `.sdlc/seed-log.md`), посев ни разу не запускался |
| Ретроспектива методологии | да | вне витка | `/sdlc-retro` независимым агентом по накопленному трению; последняя — `retros/2026-08-28-runner-local-models.md` в репозитории методологии |
| Граница scope hook'ом | нет | этап 5 | н/п — долг: во флоу `loop` границу держит политика в момент вызова (`planScope`), что строже hook'а; для флоу `sdk` строка не заведена — нарушений не было |
