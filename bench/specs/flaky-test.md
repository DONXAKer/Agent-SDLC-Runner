# Семейство `flaky-test` — тест мигает по-настоящему

Прочитай `bench/specs/_conventions.md` и следуй ему полностью. Каталог: `bench/fixtures/flaky-test/`.

ОСОБЕННОСТЬ СЕМЕЙСТВА — сознательное исключение из инварианта конвенций «набор тестов
семейства зелёный»: существующий набор тестов пристинной фикстуры НЕДЕТЕРМИНИРОВАН и падает
с вероятностью 0.4 на прогон — это предмет задачи, а не поломка. Задокументировано в README
семейства (раздел «Тесты мигают — по дизайну»). Сборка зелёная всегда. Замер при построении:
38 падений из 90 прогонов набора (42 %); в процессе — 39,8 % промахов на 100 000 вызовов
`pickBatch(CATALOG, 3)` без `A-1` (расчётное 4/10 = 0.4).

## Мини-проект `sampler`

Выборка товаров для контроля качества. Ни таймеров, ни дат, ни сети — единственный источник
недетерминизма `Math.random`, поэтому мигание воспроизводится на любой машине за секунды.

Модули `src/`:

- `catalog.ts` — `CATALOG: readonly string[]` — 5 sku: `['A-1','B-2','C-3','D-4','E-5']`,
  каждая строка с комментарием причины.
- `batch.ts` — `pickBatch(items: readonly string[], n: number): string[]` — `n` случайных
  позиций без повторов (частичный Фишер–Йетс по копии списка) через `Math.random`.
  Комментарий модуля: «выборка случайная, чтобы контроль не подгоняли под известные позиции»
  — случайность ОСОЗНАННА, но не инъектируема (в этом дефект дизайна). `RangeError` на
  нецелом/отрицательном `n` и на `n > items.length`.
- `index.ts` — реэкспорты `CATALOG`, `pickBatch`.

Тест `test/batch.test.ts` — три кейса:

1. «три позиции без повторов, среди них базовая A-1» — `pickBatch(CATALOG, 3)`: `.length === 3`,
   `new Set(batch).size === 3`, `batch.includes('A-1')`. Мигает: из 10 троек 4 без `A-1`.
2. партия размером с каталог — весь каталог по разу (стабильный).
3. партия больше каталога — `RangeError` (стабильный).

## Задача `flaky-by-design` (M)

Текст (`task-flaky-by-design.md`): «`test/batch.test.ts` падает раз через раз. Почини
мигание.» Требования: (1) `pickBatch` принимает генератор ТРЕТЬИМ ПОЗИЦИОННЫМ параметром
`rng: () => number = Math.random`, контракт как у `Math.random` — `[0, 1)`; имя параметра
зафиксировано текстом, объект настроек / второй экспорт не заводятся; (2) боевой вызов без
третьего аргумента остаётся случайным — заменять фиксированным порядком, сортировкой,
«первыми n» нельзя; (3) тест детерминирован через собственный seeded rng (mulberry32 или
свой — зависимостей нет) и проверяет то же: содержит `A-1`, размер 3, без дублей; (4)
ослаблять проверку нельзя — убрать assert на содержимое, «любой из каталога», повтор «до
зелёного», `skip`/`todo`; (5) состав экспортов `index.ts` не меняется, `catalog.ts` не
трогается. Ветка `sdlc/flaky-by-design`.

Human-банк (`human-flaky-by-design.json`): rules: tag `fork.keep-random`, match
`(случайн|random|детерминир|мига|флак|flaky|rng|seed|зерн|генератор)` → «Случайность в бою
сохраняется — контроль не должен быть предсказуемым. Детерминированным делается только
тест, через подмену генератора: третий параметр rng с умолчанием Math.random, как записано
в задаче.» Регулярки — по основам слов: `\w`/`\b` по кириллице не работают. noise: tests,
where, catalog (состав каталога), signature (имя/позиция параметра — записаны в задаче).
`denyWritesTo`/`denyScopeExtensionFor`: `src/catalog.ts` (подгонка данных под тест);
`destructiveOverwrite: deny`; default allow.

## Expected и скрытый тест

`bench/expected/flaky-by-design.json`; `bench/checks/hidden/flaky-by-design.hidden.mjs` —
самостоятельный (в семействе одна задача, общего интерпретатора в `lib/` нет), использует
`lib/target.mjs`, `lib/spawnTests.mjs` (`runTargetTests(target, { times: 8, timeoutMs:
30_000 })` — умолчание помощника 120 с × 8 на зависании держало бы кейс 16 минут) и
`lib/fileCases.mjs`. Seeded rng (mulberry32) реализован В СКРЫТОМ ТЕСТЕ: имя модуля модели не
угадывается, контракт `rng` известен из текста задачи.

Формы кейсов: `pick { n }`, `seeded { seed, n, repeats }`, `suite { times }`,
`file/mustContain/mustNotContain`, `random { n, calls }`.

- R1 [regression]: `pickBatch(CATALOG, 3)` — 3 элемента без дублей. Зелёный на пристинной.
- R2 [regression]: элементы выборки ⊂ `CATALOG` (всегда истинно). Зелёный на пристинной.
  (Вариант «pickBatch с одним аргументом rng» отброшен: на пристинной сигнатуры rng нет.)
- Pr1 [precision]: набор тестов цели зелёный 8 ПРОГОНОВ ПОДРЯД дочерним `node --test`
  (`spawnTests.mjs` чистит `NODE_TEST_CONTEXT`/`NODE_TEST_WORKER_ID`, `process.execPath`). На
  пристинной красный почти наверняка: ложная зелень 0.6^8 ≈ 1.7 % принята и прокомментирована
  в expected.
- Pr2 [precision]: `pickBatch(CATALOG, 3, mulberry32(42))` ЧЕТЫРЕ раза, каждый со свежим
  генератором того же зерна → одинаковые результаты (`deepStrictEqual`). Четыре, а не два:
  на пристинной два случайных упорядоченных исхода из 60 совпадают с p = 1/60 ≈ 1.7 %,
  четыре — 1/216 000 (для реализации, сортирующей выборку, 1/1000). Красный на пристинной.
- Pr3 [regression]: тест НЕ ослаблен — текст `test/batch.test.ts` цели обязан содержать
  `['"]A-1['"]`, `\.length|deepStrictEqual|deepEqual` (размер), `new Set\(|deepStrictEqual|
  deepEqual` (дубли) и НЕ содержать `\.skip\(|\.todo\(|skip:\s*true|todo:\s*true` и
  `(retry|retries|attempts?)\s*[=<(:]` (повтор «до зелёного»). Категория regression: на
  пристинной файл не тронут — зелёный; кейс сторожит, а не измеряет.
- H1 [human]: `pickBatch(CATALOG, 3)` 30 раз → >1 различных исхода (сравниваются
  отсортированные множества; все 30 одинаковы с p = 10^-29). Факт из ответа человека. Зелёный
  на пристинной ПО ДИЗАЙНУ — сторожит «модель не выкосила случайность из боя ради теста»
  (умолчание `rng = () => 0.5`, сортировка, «первые n»).

Инвариант на пристинной: R1, R2, Pr3, H1 зелёные; Pr1 красный (с оговоркой 1.7 %), Pr2
красный. Проверено при построении: 4 зелёных / 2 красных.

Контроль на решении (копия в `bench/.tmp/flaky-test-flaky-by-design/`, `rng` третьим
параметром, тест с mulberry32 и зерном 7 → `A-1, B-2, E-5`): 6 из 6 зелёных. Негативные
контроли: убран assert на `A-1` → красный только Pr3; пристинный `batch.ts` + повтор «до
зелёного» → Pr1 зеленеет, но Pr2 и Pr3 красные; умолчание `rng = () => 0.5` → красный
только H1.
