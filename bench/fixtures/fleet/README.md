# fleet

Нормы расхода топлива по классам автомобилей и расчёт расхода на поездку для выдачи
и списания по актам.

## Как устроено

| Модуль | Отвечает за |
|---|---|
| `src/rates.ts` | Базовая норма расхода по классу: `FUEL_RATE_DL_PER_100KM` и `rateFor`. Норма одна на класс — ни сезонных, ни поправочных коэффициентов в модели нет. Неизвестный класс даёт `null`, а не молчаливый дефолт. |
| `src/trip.ts` | Расход на поездку: `fuelMl` — километры × норму, в миллилитрах, вверх до 100 мл. |
| `src/index.ts` | Публичный контракт: снаружи вызывают только его. |

## Единицы и соглашения

- Норма хранится в **декалитрах на 100 км** (`76 дл/100км = 7.6 л/100км`). В этих единицах
  значение численно совпадает с миллилитрами на километр, поэтому таблица целочисленная,
  и в расчёте нет двоичных дробей.
- Расход — миллилитры, целое число. Итог поездки округляется **вверх** до 100 мл: акт
  выдачи пишется кратно 100 мл (цена деления мерной ёмкости), и недобор до отметки
  оплачивает парк, а не водитель.
- Процент, где он появится, округляется общим правилом пакета — **половина вверх**
  (`Math.floor(x * pct / 100 + 0.5)`), своих правил округления не заводим.
- Зимней надбавки и надбавки за прицеп в коде нет и не было — условия их применения
  уточнять у диспетчерской, они не выводятся из репозитория.

## Как запускать

```bash
node scripts/build-check.mjs      # «сборка»: загрузка всех модулей src
node --test "test/**/*.test.ts"   # тесты
```

Компиляции нет: TypeScript исполняется напрямую, типы снимает Node (нужен 23.6 или новее).
Зависимостей у пакета нет, `npm install` не требуется.
