# billing

Выставление счетов за товары: позиции, подытог, итог, данные покупателя, конфиг площадки.

## Как устроено

| Модуль | Отвечает за |
|---|---|
| `src/money.ts` | Деньги. Всё считается в **копейках** целым числом. Процент округляется **половиной вверх** — правило одно на весь расчёт. |
| `src/lines.ts` | Позиции счёта: количество × цена, подытог. Скидок и налогов здесь нет — они считаются на сборке счёта. |
| `src/customer.ts` | Данные покупателя, как они приходят из формы заказа. |
| `src/config.ts` | Конфигурация площадки. Читается через `resolveConfig`, прямых обращений к `DEFAULT_CONFIG` из модулей нет. |
| `src/invoice.ts` | Сборка счёта: подытог → слагаемые отдельными полями → итог. |
| `src/index.ts` | Публичный контракт: снаружи вызывают только его. |

## Единицы и соглашения

- Деньги — копейки, целое число. `rub(249)` → `24900`.
- Порядок расчёта закреплён: подытог по позициям → слагаемые отдельными полями → итог.
- Форма `Invoice` — контракт: её сверяют литералом в тестах. Поле добавляется в счёт,
  только когда ему есть что сказать; поле-заглушка с нулём — это молчаливая смена формы.

## Конфигурация

| Опция | Умолчание | Что задаёт |
|---|---|---|
| `currency` | `RUB` | Валюта счетов. |

## Как запускать

```bash
node scripts/build-check.mjs      # «сборка»: загрузка всех модулей src
node --test "test/**/*.test.ts"   # тесты
```

Компиляции нет: TypeScript исполняется напрямую, типы снимает Node (нужен 23.6 или новее).
Зависимостей у пакета нет, `npm install` не требуется.
