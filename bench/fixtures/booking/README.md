# booking

Бронирование доков склада: слоты, брони и их срок.

## Как устроено

| Модуль | Отвечает за |
|---|---|
| `src/clock.ts` | Время. Момент «сейчас» **инъецируется** (`Clock`, `fixedClock`, `systemClock`), ни одна функция не читает системные часы сама. Разбор ISO-строк — `instantOf`, нечитаемая строка — ошибка, а не `NaN`. |
| `src/slots.ts` | Слот дока — полуинтервал `[startIso, endIso)`; `overlaps` — пересечение. Касание концами пересечением не считается. |
| `src/hold.ts` | Бронь: `makeHold` держит слот за клиентом до срока `expiresIso`, `isActive` отвечает, действует ли бронь в заданный момент. Бронь — значение: новый объект, свой снимок слота, аргументы не мутируются. |
| `src/warehouse.ts` | Справочник складов: код и имя. |
| `src/index.ts` | Публичный контракт: снаружи вызывают только его. |

## Единицы и соглашения

- Моменты — строки ISO 8601 **с явным смещением** (обычно `Z`, как печатает
  `Date#toISOString()`). Строка без смещения читалась бы по часам машины.
- Слот — полуинтервал: начало входит, конец нет.
- «Сейчас» всегда приходит параметром `now: Date`; в тестах — из `fixedClock`.
- Часовой пояс складов в коде **не зафиксирован** — уточнять у оператора.

## Как запускать

```bash
node scripts/build-check.mjs      # «сборка»: загрузка всех модулей src
node --test "test/**/*.test.ts"   # тесты
```

Компиляции нет: TypeScript исполняется напрямую, типы снимает Node (нужен 23.6 или новее).
Зависимостей у пакета нет, `npm install` не требуется.
