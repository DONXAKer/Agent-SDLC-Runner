# unitconv

Конвертер единиц для отчётов: километры в мили, килограммы в фунты, градусы Цельсия в
Фаренгейта.

## Как устроено

| Модуль | Отвечает за |
|---|---|
| `src/convert.ts` | Коэффициенты, правило округления `round3` и сами конверторы. Правило округления одно на модуль и записано буквально — «половина вверх» читается из кода, а не из документации `Math.round`. |
| `src/index.ts` | Публичный контракт: снаружи вызывают только его. |

## Единицы и соглашения

- Расстояние: километры → мили, `1 км = 0.621371 мили` (международная миля — 1609.344 м,
  коэффициент — 1/1.609344 с точностью до шести знаков).
- Масса: килограммы → фунты, `1 кг = 2.20462 фунта` (фунт — 0.45359237 кг).
- Температура: `°F = °C × 9/5 + 32`. **Не округляется**: шкала аффинная с точным множителем,
  целые и десятые градусов с приёмки переходят без хвоста, и округление здесь либо ничего не
  делало бы, либо — на входе с бо́льшей точностью — молча её скрывало.
- Всё, что умножается на усечённый коэффициент, округляется до **трёх знаков, половина
  вверх** — `round3`. Целых чисел здесь нет: в отчёт идут дробные километры и килограммы.

## Как запускать

```bash
node scripts/build-check.mjs      # «сборка»: загрузка всех модулей src
node --test "test/**/*.test.ts"   # тесты
```

Компиляции нет: TypeScript исполняется напрямую, типы снимает Node (нужен 23.6 или новее).
Зависимостей у пакета нет, `npm install` не требуется.

## Состояние набора тестов

Набор тестов **падает на кейсе `kmToMiles(100)`** в `test/convert.test.ts` — это входные
данные задачи `broken-test`, а не поломка проекта. Сборка зелёная. Остальные кейсы зелёные.
Для бенчмарка это сознательное исключение из правила «набор пристинной фикстуры зелёный»
(`bench/specs/_conventions.md`): предмет задачи — само падение, и зелёная фикстура задачу бы
не ставила.
