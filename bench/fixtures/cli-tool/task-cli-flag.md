# Флаг `--json` у команды `quote`

Цену из `qstat quote` начали дёргать скрипты: они парсят строку `msk, 2 кг: 458 ₽` регуляркой
и ломаются на каждой правке текста. Нужен машиночитаемый вывод по флагу.

## Что должно получиться

1. Команда `quote` (`src/commands.ts`) получает флаг `--json`: с ним вывод — одна JSON-строка
   вида `{"zone":"msk","kg":2,"price":45800}`. Цена — в **копейках**, как она хранится;
   `kg` — число, не строка; ключи ровно в этом порядке (`zone`, `kg`, `price`), без пробелов
   и переводов строки — ровно то, что даёт `JSON.stringify` объекта с этими тремя полями.
2. Без флага вывод **прежний**, символ в символ: скрипты, которые ещё не перешли на JSON,
   продолжают работать.
3. Парсер аргументов (`src/args.ts`) **не переписывать**: он уже поддерживает флаги вида
   `--flag`, задача — прочитать флаг, а не научить парсер новому. Флаги ставятся после
   позиционных аргументов: `qstat quote msk 2 --json`.
4. На флаг есть тест рядом с существующими (`test/`), набор тестов прогнан по-настоящему
   командой проекта; в журнал этапа идёт то, что напечатала команда. Существующие тесты
   остаются зелёными и **без правки**.

## Рамки

- Ветка витка заведена: `sdlc/cli-flag`. Виток полный — мелким контуром не закрывать.
- Текстовый форматтер (`src/format.ts`) и тарифы в этом витке не меняются: флаг — про форму
  вывода одной команды, а не про форматирование вообще.
