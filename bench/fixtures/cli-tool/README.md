# qstat

Справка по тарифам доставки из командной строки: таблица зон и цена отправления.

## Как устроено

| Модуль | Отвечает за |
|---|---|
| `src/args.ts` | Разбор argv: команда, позиционные аргументы, флаги `--key value` и `--flag`. Своя реализация — зависимостей у пакета нет. |
| `src/tariffs.ts` | Тарифная таблица: ставка за килограмм по зоне (`msk`, `center`, `ural`, `far`) и `priceFor`. Деньги — **копейки** целым числом. |
| `src/format.ts` | Вывод для человека: `formatTable` (колонки пробелами) и `formatQuote` (строка цены). Стандарт вывода денег — **пробел между разрядами**: `1 234 ₽`. |
| `src/lookup.ts` | `quoteLine` — быстрая справка по цене одной строкой для внутренних отчётов. |
| `src/commands.ts` | `run(argv): string` — команды `list` и `quote`. |
| `src/main.ts` | Точка входа процесса: argv → `run` → stdout. Единственное место, знающее про process. |
| `src/index.ts` | Публичный контракт: снаружи вызывают только его. |

## Команды

```bash
node src/main.ts list              # таблица зон: зона, ₽/кг — без заголовка, строки по зонам
node src/main.ts quote msk 2       # msk, 2 кг: 458 ₽
```

Флаги ставятся **после** позиционных аргументов: `--key` забирает следующий токен как значение,
если тот не начинается с `--`.

## Единицы и соглашения

- Деньги — копейки, целое число; ставки прейскуранта — целые рубли за килограмм.
- Вес — целые килограммы, приёмка округляет вверх.
- Вывод денег — целые рубли, разряды отделены пробелом (`1 234 ₽`); копейки печатаются
  только когда они есть.
- Команды не трогают процесс: принимают argv массивом, возвращают строку. Ошибка ввода
  пользователя — `UsageError`, код выхода 2.

## Как запускать

```bash
node scripts/build-check.mjs      # «сборка»: загрузка всех модулей src
node --test "test/**/*.test.ts"   # тесты
```

Компиляции нет: TypeScript исполняется напрямую, типы снимает Node (нужен 23.6 или новее).
Зависимостей у пакета нет, `npm install` не требуется.
