# loyal-shop

Магазин с накопительной скидкой: сумма заказа, скидка по истории покупок клиента,
ежемесячный отчёт по клиентам.

## Как устроено

| Модуль | Отвечает за |
|---|---|
| `src/money.ts` | Деньги. Всё считается в **копейках** целым числом. Процент округляется **половиной вверх** — правило одно на весь расчёт, своего округления в других модулях не заводится. |
| `src/loyalty.ts` | Накопительная скидка: ступени по сумме прошлых покупок клиента, ставка и сумма скидки. |
| `src/order.ts` | Заказ: сумма позиций минус скидка клиента. |
| `src/report.ts` | Ежемесячный отчёт по клиентам — текст фиксированного формата, его читают люди и выгрузка. |
| `src/index.ts` | Публичный контракт: снаружи вызывают только его. |

## Накопительная скидка

Ставка зависит от суммы **всех прошлых покупок** клиента (`Account.spentTotalK`), не от
текущего заказа. Границы ступеней **включительны**: ровно на границе действует нижняя ступень.

| Покупки за всё время | Ставка |
|---|---|
| до 10 000 ₽ включительно | 0 |
| свыше 10 000 ₽ до 50 000 ₽ включительно | 3% |
| свыше 50 000 ₽ | 7% |

Скидка считается от суммы позиций заказа общим округлением пакета (половина вверх) и
вычитается из неё; итог не бывает отрицательным.

## Отчёт

Первая строка — шапка `Клиент | Покупки | Скидка`, далее по строке на клиента в порядке
передачи: идентификатор, сумма покупок в рублях (`1 234,56 ₽`), действующая ставка (`3 %`).

## Единицы и соглашения

- Деньги — копейки, целое число. `rub(249)` → `24900`.
- Порядок расчёта заказа закреплён: сумма позиций → скидка от неё → вычитание.
- Формат отчёта — контракт: его сверяют дословно в тестах.

## Как запускать

```bash
node scripts/build-check.mjs      # «сборка»: загрузка всех модулей src
node --test "test/**/*.test.ts"   # тесты
```

Компиляции нет: TypeScript исполняется напрямую, типы снимает Node (нужен 23.6 или новее).
Зависимостей у пакета нет, `npm install` не требуется.
