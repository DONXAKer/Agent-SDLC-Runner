# transfer-segments

Полный виток; исходный модуль изучить до выбора правки. Новых зависимостей нет.

## Что должно получиться

1. Создать core/segments.mjs с именованной функцией splitKey(value): строку разбить по /, пустые сегменты убрать. Пустая строка даёт [].
2. normalizeKey в core/key.mjs должна использовать splitKey и соединять результат символом двоеточия.
3. Сохранять регистр, пробелы внутри сегмента и буквальные . и ..; это ключ данных, а не путь файловой системы. Нестроковый аргумент вызывает TypeError.
4. Добавить test/additional.test.mjs, проверить несколько разделителей и пустой ключ, запустить проверки проекта.
5. Существующие тесты, src/index.ts и apiRevision сохраняются без правки. Меняются только два названных модуля и новый тест.

## Проверки

Сборка: node scripts/build-check.mjs. Тесты: node --test "test/*.test.mjs".
