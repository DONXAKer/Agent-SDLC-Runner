Export createInventory(initial) from src/inventory.mjs. initial is a record of nonnegative safe integer quantities. Copy it on construction. Return {reserve(sku,quantity),release(token),available(sku)}. reserve requires positive safe integer quantity (RangeError otherwise), returns null for unknown SKU or insufficient stock, otherwise subtracts stock and returns a unique opaque token. release returns true and restores stock once for a token issued by this instance; unknown, foreign or already released token returns false. available returns current count, or zero for unknown SKU. Instances are independent.
