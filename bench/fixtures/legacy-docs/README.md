# sales-report

Свод продаж по менеджерам за период и текстовая таблица для письма руководителю.

## Как устроено

| Модуль | Отвечает за |
|---|---|
| `src/rows.ts` | Строка продажи: менеджер и сумма чека. Деньги — **копейки**, целое число; рубли с плавающей точкой в расчёте не появляются. |
| `src/aggregate.ts` | Свод: группировка строк по менеджеру, сумма, отсев по порогу, порядок строк. Правила — ниже. |
| `src/report.ts` | Текстовая таблица поверх свода: моноширинная, колонки по содержимому. |
| `src/index.ts` | Публичный контракт: снаружи вызывают только его. |

## Правила отчёта

- Строки группируются по менеджеру; сумма — по всем его чекам за период.
- Менеджеры идут **по возрастанию суммы**: лучший — последней строкой.
- В отчёт попадают только менеджеры с суммой **строго больше 1000 ₽**; ровно 1000 ₽ в отчёт
  не попадает.
- При равенстве сумм порядок менеджеров **не определён** и зависит от порядка строк на входе.

## Единицы и соглашения

- Деньги — копейки, целое число: `120_000` — это 1 200,00 ₽.
- В таблице суммы печатаются с разрядами и запятой перед копейками: `1 200,00 ₽`.
- Пустой свод — одна строка `Отчёт пуст` вместо таблицы.

## Как запускать

```bash
node scripts/build-check.mjs      # «сборка»: загрузка всех модулей src
node --test "test/**/*.test.ts"   # тесты
```

Компиляции нет: TypeScript исполняется напрямую, типы снимает Node (нужен 23.6 или новее).
Зависимостей у пакета нет, `npm install` не требуется.
