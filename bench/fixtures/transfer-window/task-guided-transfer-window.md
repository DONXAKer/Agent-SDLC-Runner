# transfer-window

Полный виток; исходный модуль изучить до выбора правки. Новых зависимостей нет.

## Что должно получиться

1. В lib/window.mjs функция inWindow(value, start, end) проверяет полуоткрытый интервал: начало входит, конец не входит.
2. Если начало равно концу, интервал пуст для любого значения.
3. Все три аргумента должны быть конечными числами; строки, null, NaN, бесконечности и start > end приводят к TypeError.
4. Добавить test/additional.test.mjs с тестами границ и некорректных аргументов; выполнить команды проекта.
5. Существующие тесты, src/index.ts и apiRevision остаются без изменений. Другие файлы не менять.

## Проверки

Сборка: node scripts/build-check.mjs. Тесты: node --test "test/*.test.mjs".
