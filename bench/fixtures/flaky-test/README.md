# sampler

Выборка позиций каталога на контроль качества.

## Как устроено

| Модуль | Отвечает за |
|---|---|
| `src/catalog.ts` | Каталог: пять артикулов в порядке прейскуранта, только чтение. |
| `src/batch.ts` | `pickBatch` — партия из `n` **случайных** позиций без повторов. Случайность — свойство контроля: проверяющие не должны знать заранее, что попадёт на стол. |
| `src/index.ts` | Публичный контракт: снаружи вызывают только его. |

## Соглашения

- Артикулы — строки вида `A-1`; каталог не меняется во время работы.
- Партия набирается без возврата: повтор артикула в одной партии невозможен по построению.
- Партия больше каталога — ошибка (`RangeError`), а не молчаливое усечение.

## Тесты мигают — по дизайну

`test/batch.test.ts` мигает: первый кейс требует, чтобы в партии из трёх позиций оказалась
базовая `A-1`, а `pickBatch` тянет позиции через `Math.random`, и в 4 из 10 сочетаний
трёх из пяти базовой позиции нет. Набор падает примерно в **40 %** прогонов и зеленеет в
остальных, без единой правки кода. Это **входные данные задачи семейства, не поломка
фикстуры**: мигание воспроизводится на любой машине и за секунды, потому что зависит только
от `Math.random` — ни таймеров, ни дат, ни сети в проекте нет. Сборка (`build-check`)
зелёная всегда.

## Как запускать

```bash
node scripts/build-check.mjs      # «сборка»: загрузка всех модулей src
node --test "test/**/*.test.ts"   # тесты (см. раздел выше: мигают)
```

Компиляции нет: TypeScript исполняется напрямую, типы снимает Node (нужен 23.6 или новее).
Зависимостей у пакета нет, `npm install` не требуется.
