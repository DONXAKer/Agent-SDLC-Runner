# parcel-price

Расчёт цены доставки посылки по зонам и весу.

## Как устроено

| Модуль | Отвечает за |
|---|---|
| `src/money.ts` | Деньги. Всё считается в **копейках** целым числом; рубли с плавающей точкой в расчёте не появляются. Процент округляется **половиной вверх** — правило одно на весь расчёт. |
| `src/zones.ts` | Тарифная зона по коду региона получателя: `msk`, `center`, `ural`, `far`. Неизвестный код уходит в дальнюю зону. |
| `src/tariffs.ts` | Тарифная таблица (зона × весовая ступень) и `priceFor` — сборка итогового расчёта. |
| `src/discounts.ts` | Скидка лояльности. Считается **от базовой цены зоны**, не от итога. Есть потолок скидки. |
| `src/index.ts` | Публичный контракт: снаружи вызывают только его. |

## Единицы и соглашения

- Деньги — копейки, целое число. `rub(249)` → `24900`.
- Вес — граммы, уже округлённые приёмкой до границы весовой ступени.
- Габариты — сантиметры, тройка `[длина, ширина, высота]`. Порядок сторон **не нормализован**:
  приёмка вводит их так, как удобно мерить.
- Порядок расчёта закреплён: база по зоне и весу → скидка от базы → вычитание.

## Тарифы

Таблица заполнена вручную по действующему прейскуранту, каждая строка имеет причину быть
именно такой. Тариф зоны `far` уже включает коэффициент за сложную логистику сборного груза —
это про плечо и срок, а не про свойства самого отправления.

## Как запускать

```bash
node scripts/build-check.mjs      # «сборка»: загрузка всех модулей src
node --test "test/**/*.test.ts"   # тесты
```

Компиляции нет: TypeScript исполняется напрямую, типы снимает Node (нужен 23.6 или новее).
Зависимостей у пакета нет, `npm install` не требуется.
